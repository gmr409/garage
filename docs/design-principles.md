# Design Principles

## Intent

Create an upscale private automotive showroom that remains residential, restrained, and technically focused.

## Visual hierarchy

1. Vehicles are the primary focal elements.
2. The Corvette is the principal focal point through centered placement and a dark rear feature wall.
3. Engineering artwork supports the vehicles and should not compete with them.
4. Lighting should emphasize vehicle form, floor reflections, and architectural depth.

## Core rules

- Preserve the approved vehicle layout unless a variation explicitly changes it.
- Keep wall art equal in size and style.
- Maintain at least 50 cm between adjacent art pieces.
- Do not add parking lines.
- Avoid visual clutter.
- Avoid extra decorative wall art unless specifically requested.
- Prefer neutral architectural colors so the vehicles provide the strongest color accents.

## Baseline palette

- primary walls: off-white
- feature wall: dark charcoal
- floor: vivid graphite
- frames: black
- artwork backgrounds: light neutral
- lighting: approximately 4000K linear LED

## Change control

Any proposed change should be treated as one of the following:

- experiment: temporary exploration only
- variant: retained alternative derived from the baseline
- milestone: explicitly approved replacement baseline
